# Weather App with Live OpenWeather API

A Python project that retrieves current weather and a five-day forecast using the OpenWeather REST API. Includes a Streamlit web interface for a live demo and a command-line version.

## Features
- Current temperature in Celsius, humidity, feels-like temperature, conditions, and wind speed
- Five-day forecast table and CSV download
- REST API requests and JSON parsing
- Handles unknown cities, rejected keys, timeouts, and network errors
- Keeps the API key outside the source code

## Files
- `app.py` — Streamlit web application
- `cli_app.py` — command-line version
- `requirements.txt` — dependencies
- `.env.example` — environment-variable template
- `.gitignore` — excludes secrets and local environment files

## 1. Get an API key
Create an account at https://openweathermap.org/ and generate an API key. New keys may take time to activate.

## 2. Run locally
Install dependencies:
```bash
python -m pip install -r requirements.txt
```
Copy `.env.example` to a file named `.env` and replace the sample value:
```text
OPENWEATHER_KEY=your_real_api_key
```
Never upload `.env` or publish your API key.

Run the web app:
```bash
python -m streamlit run app.py
```
Or run the command-line version:
```bash
python cli_app.py
```

## 3. Publish on GitHub
Create a repository such as `Weather-App-OpenWeather-API`. Upload the project files, but do NOT upload `.env`.

## 4. Deploy a live demo
1. Open https://share.streamlit.io/ and sign in with GitHub.
2. Select **Create app**, choose your repository and branch, and set the main file path to `app.py`.
3. Open the deployed app's **Settings → Secrets** and add:
```toml
OPENWEATHER_KEY = "your_real_api_key"
```
4. Save the secret and let the app restart. Copy the public `.streamlit.app` URL as your live demo link.

## API endpoints
- Current weather: `https://api.openweathermap.org/data/2.5/weather`
- Five-day forecast: `https://api.openweathermap.org/data/2.5/forecast`

Requests use `units=metric` for Celsius.

## Security
The app reads the API key from `.env` locally or Streamlit Cloud Secrets after deployment. Do not paste the key into Python files, README files, screenshots, or public GitHub commits. If the key is exposed, revoke it and create another.

## Testing checklist
Test at least five cities, an unknown city, an empty input, a network problem, and a key that has not activated.
